طريقة التشغيل:
1. افتح index.html في المتصفح للمعاينة.
2. ارفع index.html و style.css ومجلد assets إلى جذر مستودع GitHub.
3. من Settings > Pages اختر Deploy from a branch ثم main و / (root) واحفظ.
الموقع ثابت ولا يحتاج إلى خادم أو تثبيت مكتبات. خط Cairo يُحمّل من Google Fonts عند توفر الإنترنت، مع خطوط بديلة محلية.
